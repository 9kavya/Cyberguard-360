CyberGuard 360 is a unified cybersecurity platform built in Python that scans malware, phishing links, USB threats, and network intrusions using multiple tools — generating a combined threat report.

Features:

Malware scanning using MD5/SHA hashing

USB drive malware detection

Phishing & fake URL detection

ARP-based rogue device detection

Real-time system resource monitoring

Unified threat reports with alerts

Lightweight PyQt5 GUI
