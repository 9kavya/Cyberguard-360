#CyberGuard 360 integrates malware hashing (MD5/SHA), USB scanning, phishing detection, ARP-based network intrusion detection, and real-time system monitoring into a single Python application. Scan results are combined into a unified security report with alerts and recommendations.
Features:

Malware scanning using MD5/SHA hashing

USB drive malware detection

Phishing & fake URL detection

ARP-based rogue device detection

Real-time system resource monitoring

Unified threat reports with alerts

Lightweight PyQt5 GUI
